# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability in LeadGen, please report it privately to the repository maintainer.

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential security impact
- Any relevant logs, screenshots, or proof of concept
- Suggested remediation, if available

Please do not publicly disclose the vulnerability until it has been investigated and, where appropriate, fixed.

## Scope

This policy applies to the code and configuration contained in this repository.

## Security Practices

The project aims to:

- Keep dependencies up to date
- Avoid committing secrets or credentials
- Run automated security checks
- Review changes before merging
- Use GitHub security features where available
